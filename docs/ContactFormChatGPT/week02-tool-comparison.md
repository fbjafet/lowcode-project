Gemini - Create the contact form without much interaction, it run freely. Presented the code in a not much clear way. Very simple contact form layout.
 
## Which I kept, and why
I choose ChatGPT version for its correctness, and completeness. The user experience was better, the code and documentation were clearer. In the final overview, running the security testes, ChatGPT version performed better.
